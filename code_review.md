# How to review AI-generated code

- **Correctness:** does it satisfy each acceptance criterion?
- **Readability:** can the author explain each function?
- **Robustness:** what happens with empty or unexpected input?
- **Security:** does it expose secrets, trust input, or use unsafe execution?
- **Maintainability:** are names and structure clear?
- **Verification:** run the program and tests in a safe environment.
